# my-legal

Нотатки та інструкції щодо життєвих ситуацій, пов'язаних з юридичними питаннями:
легалізація, документи та паперові нюанси у взаємодії з державними і недержавними органами.

## Структура

Кожна ситуація - окремий файл або папка з описом:

- що потрібно зробити і навіщо;
- перелік документів;
- куди звертатися, строки та вартість;
- підводні камені та корисні посилання.

> Особисті документи (скани, паспорти, номери) не зберігаються в цьому репозиторії -
> для них є папка `private/`, яка виключена з git.
